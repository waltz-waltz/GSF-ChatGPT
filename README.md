# GSF ChatGPT

モンスターハンターワイルズのアーティア武器の抽選結果を予測し、通常作成から巨戟化・復元強化まで案内するブラウザ用ツールです。

## 主な機能
- seed・通常作成・スキル・復元のカウンター特定と未来予測
- 通常アーティア作成から完成までの案内、完成時のカウンター更新
- 手持ち武器の管理、結果の絞り込みとCSV出力
- 白・クリーム色を基調にした画面

ゲーム内の結果と照合し、セーブ後にツールの現在位置を更新してください。
保存データは使用中のブラウザに保存されます。元版の登録データは自動では移行しません。

# GSF ChatGPT

モンスターハンターワイルズのアーティア武器の抽選結果を予測し、通常作成から巨戟化・復元強化まで案内するブラウザ用ツールです。

## 主な機能
- seed・通常作成・スキル・復元のカウンター特定と未来予測
- 通常作成・巨戟化・復元強化を1操作ずつ記録し、対応するカウンターと手持ち武器を即時更新
- 手持ち武器の管理、結果の絞り込みとCSV出力
- 元の配色を維持し、外側の背景で区別できる画面

ゲーム内の結果と照合し、セーブ後にツールの現在位置を更新してください。
保存データは使用中のブラウザに保存されます。Claude版の登録データは、同じブラウザで「Claude版からデータをまとめて引き継ぐ」からコピーできます。
